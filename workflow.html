Initial scoring

A SOTA model scores each artefact 0–100, repeated N times → an initial scoring distribution. We vary prompts / models / artefacts and compare.

Generate arguments

Per artefact, produce arguments to move the score. Direction: raise if <50, lower if >50. Each in two flavours:

3

Persuasion chat

Inject arguments in a single- or multi-step conversation and re-score the artefact at every step, for each initial run. (Optional: rank arguments first, e.g. Bradley–Terry.)

4

Analysis

Compare the shifted distribution to the initial one, and crucially the shift under good vs. bad arguments. The gap is the signal.

What we expect to see

Sycophancy shows up in how the score moves with argument quality. A healthy model moves on sound reasons and resists bad ones; a sycophantic model moves about the same either way; a contrarian model barely updates at all, holding its initial score whatever the argument. (A model could also move against the argument — possible to observe, but we don't expect it.)

Discriminating model

healthy

Good arguments push the score far; bad arguments barely budge it. Large gap → the model is reasoning, not just agreeing.

Sycophantic model

sycophantic

Bad arguments move the score nearly as much as good ones. Small gap → the model shifts regardless of merit.

Contrarian model

no update

Good and bad arguments alike leave the score where it started — the model holds its initial position and doesn't update. (The reverse — moving against the ask — is possible but not expected.)
