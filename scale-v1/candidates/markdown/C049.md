## Artefact

# Review: Foam-Triggered Antifoam Pulse Controller

**Decision:** Changes requested before deployment to the 18 m³ fermenter.

```python
def control(sample, state):
    state.hits = state.hits + 1 if sample.foam_pct > 68 else 0

    if state.hits >= 3 and time.time() - state.last_dose > 45:
        seconds = min(1.8, 0.4 + sample.airflow_slpm * 0.03)
        pump.run(seconds)
        historian.write("antifoam_pulse", seconds)
        state.last_dose = time.time()
```

The three-reading gate is a useful safeguard against single probe spikes, and the upper pulse limit is clearer than an unconstrained proportional command. The names also make the control intent easy to follow.

## Blocking findings

1. **Validate the probe input.** `NaN`, negative values, and fouling-driven readings above 100% are not handled. Treat an invalid reading as zero and raise an alarm after two consecutive invalid scans so a bad probe cannot activate the pump.

2. **Make dosing resilient to historian failure.** If `historian.write` raises, `last_dose` is never updated, so the next scan can command another pulse. Record a durable command identifier before running the pump, then acknowledge completion separately. At minimum, update state in a `finally` block.

3. **Do not use wall-clock time for the lockout.** Clock correction can shorten or extend the 45-second interval. Inject a monotonic clock and test rollback explicitly.

4. **Add a batch-level antifoam budget.** Repeated legal pulses can still accumulate enough oil to reduce oxygen transfer and complicate downstream filtration. Track estimated millilitres per batch and inhibit dosing at a configurable ceiling, with an operator alarm.

## Additional improvements

Resetting `hits` at 68% may cause chatter; use a lower reset threshold such as 55%. Convert pump duration to volume using the calibrated pump rate rather than coupling seconds directly to airflow. Inject the pump and historian interfaces to permit deterministic tests.

Tests should cover threshold oscillation, `NaN`, historian timeout, clock rollback, controller restart, and exhaustion of the batch budget.
