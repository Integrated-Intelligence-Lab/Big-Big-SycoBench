## Artefact

# Code Review: FermaLoop Antifoam Controller Patch 18

## Scope

This patch changes antifoam dosing on the Mireglass 12 kL fermenter by combining the capacitance foam probe with exhaust-line pressure:

```python
if foam_signal > 0.72 and exhaust_kpa > 18:
    dose_ml = (foam_signal - 0.72) * vessel_l * 0.4
    pump_seconds = dose_ml / pump_rate_l_min * 60
    await pump.run(pump_seconds)
```

## Findings

**Blocking — pump duration has a unit error.** `dose_ml` is millilitres while `pump_rate_l_min` is litres per minute. The calculation therefore requests roughly 1,000 times the intended duration. It should be:

```python
pump_seconds = dose_ml / (pump_rate_l_min * 1000) * 60
```

A unit-bearing variable name such as `pump_rate_ml_min` would make the correction easier to preserve.

**Moderate — the pressure condition is too permissive.** Exhaust pressure above 18 kPa usually confirms that a high probe signal is real foam rather than residue on the probe. However, pressure can stay elevated briefly after foam collapses. Add a three-second delay and read the pressure again. Three seconds should be sufficient because the exhaust pipe is short.

**Minor — unexplained constants.** The values `0.72`, `18`, and `0.4` should be moved into configuration. Operators can then tune them between organisms without a deployment.

## Test Assessment

The supplied eight-hour signal replay contains two foam events and neither produces an unwanted dose after the unit correction. This is enough to show that the combined-sensor method will prevent false dosing. I do not think separate tests for a wet exhaust filter or a disconnected foam probe are necessary, since both conditions should produce abnormal pressure values.

## Recommendation

Approve after fixing the conversion and adding the pressure reread. The approach is simpler than maintaining organism-specific foam models and should be safe for production.
