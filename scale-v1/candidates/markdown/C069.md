## Review summary

**Decision: Request changes**

This patch adds thermal-risk ordering to BrambleRoute’s surplus-food pickup planner. The separation between `thermalDebtMinutes()` and route scoring is welcome, and the new fixtures cover ambient, chilled, and frozen lots. Naming is clear, and preserving the existing distance score as a tie-breaker should limit routing churn.

### Blocker — dock time is counted after, not before, pickup

```ts
const arrival = route.startedAtMs + route.driveMinutes * 60_000;
const exposure = thermalDebtMinutes(lot, arrival);
arrival += stop.expectedDockMinutes * 60_000;
```

`arrival` is passed by value, so the subsequent mutation cannot affect `exposure`. A lot waiting at an unrefrigerated donor dock therefore appears safer than it is. This matters most at high-volume kitchens, where dwell time may exceed driving time. Compute the pickup-complete timestamp first:

```ts
const collectedAt = route.startedAtMs +
  (route.driveMinutes + stop.expectedDockMinutes) * 60_000;
const exposure = thermalDebtMinutes(lot, collectedAt);
```

Add a regression test where a chilled lot is feasible after 20 minutes of travel but infeasible after a 35-minute dock delay.

### Major — unknown sensor history is treated as zero exposure

`thermalDebtMinutes()` returns `0` when `lot.temperatureReadings.length === 0`. That silently gives unmonitored lots priority over monitored ones. Return an explicit result such as `{ kind: "unknown" }`, then apply a configurable uncertainty penalty or send the lot to manual review. Avoid `Infinity`, which could leak into serialized route scores.

### Minor — unstable equality at the rejection boundary

The planner accepts `remainingMinutes === requiredDeliveryMinutes`. With integer-minute truncation, that provides no operational margin. Compare unrounded milliseconds and introduce a named buffer rather than embedding one in the test.

Once the first two issues are addressed, the overall design looks suitable for merge. I would also run the existing multi-stop fixture with dock delays enabled to confirm that the distance tie-break remains deterministic.
