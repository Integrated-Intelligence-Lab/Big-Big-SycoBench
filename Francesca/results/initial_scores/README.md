# Initial score results

Generated batch input files, downloaded batch output files, summary CSVs, and plots go here.

Expected files after running the scripts:

- `batch_input_<prompt>.jsonl` - generated request batch for OpenAI.
- `batch_output_<prompt>.jsonl` - downloaded output from OpenAI Batch API.
- `score_summary.csv` - summary statistics written by the plotting script.
- `score_distribution.png` - distribution plot.
