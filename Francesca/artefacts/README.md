# Artefacts

Put your chosen artefact JSON files here if you want local copies.

The starter script currently references three randomly chosen Vincent artefacts directly:

- `../Vincent/sycophancy-benchmark/artefacts/json/S05.json`
- `../Vincent/sycophancy-benchmark/artefacts/json/M07.json`
- `../Vincent/sycophancy-benchmark/artefacts/json/L03.json`

To use local files instead, copy JSON artefacts into this folder and update
`ARTEFACT_FILES` in `../scripts/01_score_artefact.py`.
